# Анализ вакансий аналитиков данных

Скрипт раз в сутки собирает вакансии с портала «Работа в России»
([trudvsem.ru](https://trudvsem.ru)) через открытый API и сохраняет
срезы в SQLite. Из накопленной истории строится анализ рынка:
динамика числа вакансий, регионы, работодатели, зарплаты.

## Статус
В разработке: сбор данных готов, анализ и дашборд в работе.

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python collect.py
```
Данные сохраняются в `data/vacancies.db`.
